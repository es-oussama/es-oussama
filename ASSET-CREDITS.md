# Visual assets

- The current cover is a native SVG illustration of a conceptual neural network. The signal-propagation animation is a design treatment, not a running model, activity indicator or experimental result. It completes in less than five seconds; reduced-motion preferences produce a static diagram.
- Project cards are original SVG illustrations grounded in the six documented projects. They show stylized concepts rather than exact architecture blueprints, clinical images, screenshots or evaluation outputs. Their glyphs come from [Tabler Icons](https://github.com/tabler/tabler-icons), via @tabler/icons-react 3.49.0. License: [MIT](assets/TABLER-LICENSE.txt).
- The OE monogram uses the exact existing portfolio paths, proportions and forest/mint brand colors.
- Earlier cover artwork, retained in the repository history and existing asset files, was generated with OpenAI Imagegen. It is no longer the active README cover.

No statistics, visitor counters or remote runtime widgets are used.
