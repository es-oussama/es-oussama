# Visual assets

- The cover artwork was generated specifically for this profile with OpenAI Imagegen. Its glass layers and ribbon are an abstract visual metaphor, not a scientific figure or project output. WebP copies are optimized for the browser.
- Project cards are original SVG layouts showing simplified workflows grounded in the six documented projects. Their glyphs come from [Tabler Icons](https://github.com/tabler/tabler-icons), via @tabler/icons-react 3.49.0. License: [MIT](assets/TABLER-LICENSE.txt).
- The original OE identity remains the portfolio's existing brand asset. Its source is preserved in the existing header SVG files.

No statistics, visitor counters or remote runtime widgets are used.
